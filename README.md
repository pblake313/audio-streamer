# Audio Streamer
To view project details, screenshots, and a live production demo, visit:  
https://demo.pattsway.com/project-details

Audio Streamer is a full-stack application built with **Svelte/SvelteKit** on the frontend and **Node.js/Express** on the backend, with **Firestore** as the primary database.

## Run Locally
Clone the project

```bash
  git clone https://github.com/pblake313/audio-streamer
```

**Front End**
Navigate to /frontend and follow the instructions in its README.

**Back End**
Navigate to /backend and follow the instructions in its README.
